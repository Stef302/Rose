// LE LANGAGE

Né dans le jardin, taillé pour le code

ROSE est un langage compilé, statiquement typé, pensé pour se lire vite et s'écrire juste. Chaque concept porte un nom de jardin : une fonction est une rose, une variable pousse, une liste une tige, un module un jardin.

Le compilateur tranche votre code comme un sécateur : net, sans bavure. Chaque épine (erreur) est signalée avant l'exécution, jamais dans les mains de l'utilisateur.

// FONCTIONNALITÉS

Un jardin bien outillé

SYNTAXE FLORALE

Des mots-clés en français jardinier, lisibles au premier coup d'œil. Le code se lit comme un plan de jardin.

TYPAGE ÉPINEUX

Un typage statique qui pique : chaque erreur de type se prend dans les doigts du compilateur, jamais en production.

RACINES PORTABLES

PÉTALES PARALLÈLES

Bienvenue dans ROSE 🌹

          
ROSE est un langage de programmation compilé et statiquement typé, inspiré par la beauté naturelle et la rigueur mathématique. Il vise à offrir une syntaxe claire, une compilation ultra-rapide et une expérience développeur sans compromis.

          
Philosophie

          
Le code doit se lire comme un jardin bien ordonné : chaque plante a sa place, chaque épine protège ce qui est précieux, et la récolte est abondante.

          
Principes

          
    
            
  • ✿ Netteté — pas de syntaxe ambiguë, pas de magie cachée
    • 
            
  • ✿ Vitesse — compilation instantanée, exécution performante
    • 
            
  • ✿ Robustesse — le compilateur trouve les erreurs avant toi
    • 
            
  • ✿ Ouverture — MIT, open source, communautaire
    •

Premier programme

          
Créons un fichier bonjour.rose et écrivons notre première rose :

          

            
bonjour.rose


jardin bonjour {
  rose principal() {
    imprimer("Bonjour le monde !")
  }
}

          

          
Exécution :

          

            
terminal


$ rose run bonjour.rose
Bonjour le monde !

          

        


        

          
Syntaxe

          
ROSE utilise une syntaxe minimaliste inspirée de Rust et Python, mais avec son propre vocabulaire jardinier :

          

            
MOT-CLÉÉQUIVALENTRÔLE

            
rosefunc / defDéfinit une fonction

            
pousselet / varLie une variable

            
fleurirreturnRetourne une valeur

            
jardinmodule / namespaceGroupe de code

            
tigearray / listCollection ordonnée

            
épineerror / exceptionErreur propagée

            
greffetrait / interfaceContrat de type

          

          
Identificateurs

          
Les noms de variables et fonctions commencent par une minuscule, les types par une majuscule :

          

            
exemple


pousse age : Entier = 42
pousse nom : Texte = "Ada"
pousse actif : Bool = vrai

          

        


        

          
Types

          
ROSE propose un jeu de types primitifs et composable :

          

            
TYPEDESCRIPTIONEXEMPLE

Boolvrai / fauxvrai

Option<T>Valeur ou videQuelqueChose(x)

Inférence

          
Le type est souvent inféré automatiquement, sauf pour les fonctions qui nécessitent une signature explicite :

          

            
exemple


pousse x = 42         // inféré comme Entier
pousse s = "bonjour" // inféré comme Texte
pousse l : Tige<Entier> = [1,2,3]

          

        


        

          
Structures de contrôle

          
si / sinon

          

            
exemple


si age >= 18 {
  imprimer("majeur")
} sinon {
  imprimer("mineur")
}

          

          
boucles

          

            
exemple


pour chaque n dans [0..10] {
  imprimer(n)
}

tant que x > 0 {
  x = x - 1
}

          

        


        

          
Fonctions (roses)

          
Une fonction en ROSE s'appelle une rose. Elle a toujours une signature claire :

          

            
exemple


rose factorielle(n : Entier) -> Entier {
  si n <= 1 { fleurir 1 }
  fleurir n * factorielle(n - 1)
}

          

          
Fonctions pures

          
ROSE distingue les roses pures (sans effets de bord) des roses impures. Une rose pure est annotée pure :

          

            
exemple


rose pure carré(n : Entier) -> Entier {
  fleurir n * n
}

          

        


        

          
Jardins (modules)

          
Un jardin est l'unité de modularité. Chaque fichier .rose définit un jardin :

          

            
math.rose


jardin math {
  export rose pi() -> Flottant {
    fleurir 3.14159265358979
  }
}

          

          
Pour importer depuis un autre jardin :

          

            
main.rose


importer math.*
jardin main {
  imprimer(pi())
}

          

        


        

          
Tiges (listes)

          
Une tige est une collection ordonnée et typée. Elle supporte toutes les opérations classiques :

          

            
exemple


pousse fruits : Tige<Texte> = ["pomme", "poire", "cerise"]

fruits.filtrer(|f| f != "poire")
      .cartographier(|f| f.majuscule())
      |> imprimer()

          

          
Opérations principales

          
    
            
  • ✿ .longueur() — taille
    • 
            
  • ✿ .ajouter(x) — append
    • 
            
  • ✿ .filtrer(f) — filter
    • 
            
  • ✿ .cartographier(f) — map
    • 
            
  • ✿ .reduire(f, acc) — reduce
    • 
          

        


        

          
Épines (erreurs)

          
ROSE utilise les épines au lieu des exceptions : elles doivent être traitées explicitement. Cela garantit qu'aucune erreur n'est ignorée.

          

            
exemple


épine DivisionParZero

rose diviser(a : Entier, b : Entier) -> Résultat<Entier, DivisionParZero> {
  si b == 0 { fleurir Mauvais(DivisionParZero) }
  fleurir Bon(a / b)
}

          

          
Traitement :

          

            
exemple


selon diviser(10, 0) {
  Bon(v) => imprimer(v),
  Mauvais(e) => imprimer("Erreur : division par zéro")
}
