Rose 2.0 — page minimale

Version allégée de la démo : une zone de code, un bouton, la sortie. La page index.html ajoute le rendu LaTeX, l'analyse et les exemples.

Construire le module WebAssembly

# 1. cible WASM (une seule fois)
rustup target add wasm32-unknown-unknown

# 2. compilation (bibliothèque seule : le binaire natif n'est pas visé)
cargo build --release --target wasm32-unknown-unknown --no-default-features --lib

# 3. copie du module dans le dossier web/
cp target/wasm32-unknown-unknown/release/rose.wasm web/

Le module s'appelle rose.wasm et doit se trouver à côté de cette page. Un serveur HTTP est nécessaire (les modules WASM ne se chargent pas depuis file://) : python3 -m http.server -d web 8080, puis http://localhost:8080/demo.html.
