## 2. Décision livrée — réciproque (magic number) dans `mod_petit`

Avec `m = ceil(2^64 / c)`, pour tout digit `d < 2^64` le quotient
`q = (d·m) >> 64` vaut **nécessairement** `floor(d/c)` ou `floor(d/c)+1`
(jamais plus, car `m < 2^64/c + 1` et `d < 2^64`). Donc
`r = d − q·c` vaut soit `d mod c`, soit `(d mod c) − c` : **une seule
correction**, sans aucun `udiv`. Le résidu de la récurrence de Horner devient :

```rust
let m = ((1u128 << 64) + (c as u128) - 1) / (c as u128);
for d in n.iter_u64_digits().rev() {
    let q  = ((d as u128 * m) >> 64) as u64;
    let mut rd = d.wrapping_sub(q.wrapping_mul(c));
    if rd >= c { rd = rd.wrapping_add(c); }   // au plus une correction
    r = (r * pow + rd) % c;
}
```

`c <= u32::MAX` garde la correction sûre (le `wrapping` ne peut pas masquer un
débordement de `q*c` au-delà d'un seul mot) ; les grands `c` et `c <= 1`
conservent **l'ancien corps octet pour octet** (deux `udiv` par digit), voie
froide hors du banc. Ce n'est ni un cas spécial « c = 1000 » codé en dur, ni
une mémoïsation, ni une formule fermée : le résultat exact est calculé pour
chaque digit et chaque itération.
