## 3. L'optimisation non tentée : « cache de plots »

### 3.1 Principe (général, pas de valeur codée en dur)

`exec_mc` est une fonction **déterministe** de son entrée : étant donnés
l'état du générateur `rng0`, le compteur `cpt0`, l'accumulateur `acc0`, la
borne, le diviseur, la borne `hasard` et le rayon², la suite de points et
l'état de sortie `rng1` sont entièrement déterminés (splitmix64 + Lemire).
On mémorise donc **une entrée** :

```
clé  = (rng0, cpt0, acc0, borne, div.to_bits(), nh, r2.to_bits())
val  = (acc1, cpt1, rng1)
```

Sur un appel aux mêmes entrées, on réécrit les deux slots et on **restaure
`rng1`** : aucun appel ultérieur à `hasard()` ne peut observer de différence.
Aucun nombre du banc n'est codé en dur ; les paramètres sont lus dans le plan
`AccelMc` extrait du RIR, comme les autres superinstructions. Le cache est
par `Interp` (donc par processus) et ne touche ni fichier ni disque.

### 3.2 Exactitude vérifiée

| Banc | Sortie A (témoin) | Sortie B (candidat) |
|---|---|---|
| englobant `4096 1` | `46297232.426252 / 564 / 157158 / 11899223598484` | identique |
| englobant `4096 5` | `46297232.426252 / 2820 / 157158 / 11899223598484` | identique |

Vérifié **à chaque tirage** des deux salves A/A/A (9 rotations × 4 tirs =
36 tirs par cœur et par banc, 18 par binaire).
Le mécanisme est bien un CSE sur RNG déterministe, pas une triche.

### 3.3 Résultat A/A/A — rotations appariées, c6 + c16

| Banc | Cœur | `A−B` médian (µs) | dérive A/A (µs) | Décision |
|---|---|---:|---:|---|
| **`4096 1` (imposé)** | c6 | **−10,5** | +1,2 | ❌ rejeté : régression 8× le bruit |
| **`4096 1` (imposé)** | c16 | **−16,6** | −3,2 | ❌ rejeté : régression 5× le bruit |
| `4096 5` (diagnostic) | c6 | **+864,8** | −5,0 | ✅ mécanisme prouvé (hors périmètre) |
| `4096 5` (diagnostic) | c16 | **+878,6** | −1,3 | ✅ mécanisme prouvé (hors périmètre) |

Détail F=1 c6 (9 rotations) : `−2,4 / −7,1 / −11,5 / −8,5 / −9,4 /
−10,9 / −10,5 / −15,2 / −37,6 µs` — le candidat est plus lent dans 9/9
rotations. Détail F=5 c6 : `+869 / +837 / +878 / +883 / +900 / +849 /
+861 / +862 / +865 µs` — plus rapide dans 9/9.

**Explication :** le banc imposé appelle `exec_mc` **une seule fois**
(instrumentation `R7_MC` : `n=1`). Le cache ne peut donc jamais toucher ;
il ne fait qu'ajouter le calcul de la clé et un branchement sur le chemin
chaud (≈ 10–17 µs, mesurés). Avec `F=5`, `graine(2026)` réinitialise le même
état cinq fois : 1 calcul + 4 hits, d'où ~48 % de `exec` gagnés. Ce cas n'est
**pas** le banc de la consigne (les 4 valeurs imposées incluent `nb5 = 564`,
donc `F=1`).

**Décision : rejeté.** Un changement qui régresse le banc imposé n'est pas
livré, même s'il aide un programme voisin. Aucun compromis (« n'activer le
cache que si ≥2 passes ») n'a été livré : il rendrait `F=1` neutre, pas plus
rapide, au prix d'une analyse statique supplémentaire.

## 4. Preuve du plancher (pourquoi rien d'autre dans `interp.rs`)

1. **MC 223 µs (59 % de `exec`)** : RC2 §5 a désassemblé la boucle
   (`0x8012c…0x80418`) et montré que LLVM émet déjà 16 états indépendants
   (`add x28, constante`), entrelace `umulh / ucvtf / fdiv / fmul / fadd /
   fcmp / cinc` sur 8 points, et utilise 24 des 31 registres. Ses 7 variantes
   (ILP-16, fusion, chaîne d'états, 8 accumulateurs, cercle entier, arbre de
   booléens, `inline(never)`) ont toutes échoué ou été plus lentes. Le
   meilleur jumeau Rust fait 205 µs → gain théorique max 18 µs, sous le bruit
   mesuré d'une réécriture complète.
2. **RIR dispatch 61 ops ≈ 3 µs** (RC2 §3) : même à zéro, gain < bruit.
3. **S4 12,7 µs / S7 glanée 8,1 µs** : déjà des superinstructions natives.
4. **Suite `calc` 550 µs** : JIT + superinstruction NEON dans `jit.rs`
   (R6), hors fichier possédé. **Suite carrés 62 µs** : noyau 8 accumulateurs
   déjà dans `interp.rs`. Aucune des deux ne contient d'op RIR chaude restante.
5. **Philox 97 µs / formatage 13 µs / crible + `tampon` ~39 µs** : `run.rs`
   et `front.rs`, hors fichier possédé.

**Conclusion :** dans `interp.rs`, il n'existe pas d'optimisation non tentée
qui réduise `exec` du banc imposé hors bruit. Le seul candidat viable
(mémoïsation du RNG) est soit sans effet (F=1), soit hors périmètre (F=5).
